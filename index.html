News Web Scraper → WordPress Publisher

GitHub repo here

A set of Node.js crawlers for news websites that fetch recent articles and publish them to WordPress via REST API, with de‑duplication and basic normalization.

Main features
  • Multi‑site crawling: per‑site adapters (selectors) to extract title, excerpt, body, author, published date, cover image.
  • Recency filter: only picks articles newer than the last run; prevents re‑posting.
  • De‑duplication: compares URLs and titles (string similarity) to avoid duplicates.
  • Content cleanup: strips trackers/inline styles, normalizes headings and links.
  • Saves raw payloads to JSON for audit/debug before publish.
Stack
  • Node.js + TypeScript.
  • Cheerio for HTML parsing
  • Axios for HTTP with retry & rate‑limit.
  • Dotenv for environment config; Winston for logs.
WordPress integration
  • Publishes via WP REST API.
  • Maps categories/tags; sets featured image if available.
  • Custom fields/meta: original URL, source, published_at.
  • Idempotent create‑or‑skip logic based on source URL.
Operations
  • CLI commands to run per‑source or all sources; cron‑friendly (e.g., every hour).
  • Configurable concurrency, per‑site rate limits and timeouts.
  • Error handling with backoff; summary report at the end.
